# 山ルート帳（オフライン対応版）

登山ルートと登頂記録を管理するWebアプリです。
GitHub Pagesで公開し、データはFirebase（Firestore）に保存します。
一度開けば、圏外でも閲覧・登頂記録の追加ができます（電波が戻ると自動で同期）。

## ファイル構成

| ファイル | 内容 |
|---|---|
| index.html / style.css / app.js | アプリ本体 |
| firebase-config.js | **Firebaseの設定を貼り付けるファイル** |
| vendor/firebase.js | Firebase SDK（13.4.0）。圏外でも動くように同梱 |
| sw.js / manifest.webmanifest / icons/ | ホーム画面に追加・オフライン起動用 |
| firestore.rules | Firestoreのセキュリティルール（コンソールに貼る用） |

## セットアップ手順

### 1. Firebaseプロジェクトを作る
1. https://console.firebase.google.com/ を開き「プロジェクトを作成」
2. 名前は自由（例：yama-route-book）。Googleアナリティクスはオフで大丈夫です
3. 料金プランは **Spark（無料）のまま** でOK

### 2. ログインを有効にする
1. 左メニュー「Authentication」→「始める」
2. 「ログイン方法」タブ →「メール / パスワード」→ 有効にして保存
3. 「ユーザー」タブ →「ユーザーを追加」→ 自分のメールアドレスとパスワードを登録
   （このアプリには新規登録画面はありません。ここで作ったアカウントでログインします）

### 3. データベース（Firestore）を作る
1. 左メニュー「Firestore Database」→「データベースを作成」
2. ロケーションは `asia-northeast1`（東京）か `asia-northeast2`（大阪）がおすすめ（後から変更できません）
3. 「本番環境モード」で開始
4. 作成後「ルール」タブを開き、中身を全部消して `firestore.rules` の内容を貼り付け →「公開」

### 4. 設定をコピーする
1. 左上の歯車 →「プロジェクトの設定」
2. 下の「マイアプリ」でウェブアイコン `</>` をクリック → アプリ名を入れて登録（Hostingのチェックは不要）
3. 表示される `const firebaseConfig = { ... }` の `{ }` の中身を、`firebase-config.js` に貼り付け

```js
export const firebaseConfig = {
  apiKey: "AIza...",
  authDomain: "xxxx.firebaseapp.com",
  projectId: "xxxx",
  storageBucket: "xxxx.firebasestorage.app",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcdef"
};
```

> この設定値は公開されても問題ない種類のものです。データは手順3のルールで「ログインした本人だけ」読み書きできるよう守られています。

### 5. GitHub Pagesで公開する
1. GitHubで新しいリポジトリを作成（例：`yama-route-book`、**Public**）
2. 「uploading an existing file」から、このフォルダの中身をすべてドラッグ＆ドロップ → Commit
   （`vendor` と `icons` フォルダもそのまま入れてください）
3. リポジトリの「Settings」→「Pages」→ Branch を `main` / `/(root)` にして Save
4. 1〜2分後、`https://ユーザー名.github.io/yama-route-book/` で開けます

### 6. スマホのホーム画面に追加する
- **iPhone**：Safariで開く → 共有ボタン →「ホーム画面に追加」
- **Android**：Chromeで開く → メニュー →「ホーム画面に追加」（または「アプリをインストール」）

ホーム画面のアイコンから開き、**電波のある場所で一度ログイン**してください。
タイトルの横が「同期済み」になれば、画像も含めて端末に保存されています。

## 使い方のポイント

- **圏外で使うとき**：上部に「圏外・オフライン」と表示されます。閲覧・登頂記録・編集はそのままできます。変更は「未送信あり」となり、電波が戻ると自動で送信されます。
- **出発前**：電波のあるうちに一度アプリを開いて「同期済み」を確認しておくと安心です。
- **ログアウトしない**：圏外ではログインし直せないので、普段はログインしたままにしてください。
- **iPhoneはホーム画面から使う**：Safariのタブで使うと、しばらく開かないと端末のデータが消されることがあります。ホーム画面に追加したアプリなら大丈夫です。
- **バックアップ**：一覧画面の「⋯」→「バックアップを書き出す（画像込み）」でJSONファイルに保存できます。

## 今のページ（claude.ai版）からの引っ越し
1. 今のページで「書き出し」→「画像込みでファイル保存（引っ越し用）」
2. 新しいアプリで「⋯」→「バックアップを読み込む」→ そのファイルを選択

## 無料枠について（Sparkプラン）
- 保存容量 1GiB まで。画像は1枚あたり最大約0.9MBに自動圧縮するので、数百枚程度なら余裕があります
- 個人で使う範囲なら、読み書きの回数制限に届くことはまずありません

## アプリを更新したとき
ファイルを差し替えたら `sw.js` の `VERSION`（例：`"v1"` → `"v2"`）を上げてください。
次に開いたとき裏で新しい版が取得され、その次に開いたときから反映されます。
